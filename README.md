# Wine Classification Model 🍷

## Project Overview

This project uses PyTorch to build a neural network that predicts which of three wine varieties a sample belongs to.

## Objective

To apply fundamental deep learning concepts using PyTorch to solve a multiclass classification problem.

## Technologies Used

* Python
* PyTorch
* NumPy
* Scikit-learn
* Jupyter Notebook

## Dataset

The project uses the Wine dataset provided by Scikit-learn. It contains chemical measurements of wine samples belonging to three different classes.

## Methodology

The project will follow these steps:

1. Load and explore the dataset.
2. Split the data into training and testing sets.
3. Standardize the features.
4. Convert the data into PyTorch tensors.
5. Build and train a neural network.
6. Evaluate the model using test accuracy.
